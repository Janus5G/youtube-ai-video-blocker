# Security Policy

## Reporting a vulnerability

Please avoid publishing security-sensitive details in a public issue before the issue can be reviewed.

If GitHub Private Vulnerability Reporting is enabled for this repository, use the repository's **Security** tab to submit a private vulnerability report.

Please include:

- A clear description of the issue.
- Steps to reproduce it.
- The affected browser/version when relevant.
- The expected and observed behaviour.

This project is a local browser content filter and should not require credentials, API keys or other secrets. Do not include personal data or credentials in reports.
